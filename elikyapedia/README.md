# ELIKYAPEDIA - première édition

Publication du 3 novembre 2026, version 1.0. Trois dossiers, six articles, trois cahiers PDF.

Les textes sont regroupés dans `edition-v1.0.json`. Le catalogue documentaire public et la provenance sont dans `sources.json`. Les pages statiques sont directement publiables sur GitHub Pages, sans dépendance ni JavaScript côté visiteur.

## Arborescence

- `index.html` : répertoire des trois domaines.
- `energie/`, `finances-publiques/`, `agriculture/` : dossiers, puis sous-dossier `articles/`.
- `documents/` : trois cahiers PDF versionnés, identiques aux textes de cette édition.
- `sources.html`, `sources.json` : références et limites.
- `methode.html` : périmètre, statut éditorial et règles de correction.
- `edition.css` : adaptations locales ; la feuille principale du site reste inchangée.

## Maintenance

Pour toute correction, garder les pages HTML, le corpus JSON et le PDF concerné cohérents, puis modifier la version et la date. Ne pas assimiler date de publication et millésime des données. Conserver les versions antérieures dans l’historique Git. Aucun transfert automatique Drive-site et aucune contribution publique automatique ne sont actifs.

Ne pas republier de fichiers Drive non vérifiés, d’accusations individuelles, de données personnelles ou d’annexes seulement annoncées dans les recherches. Les rapports institutionnels tiers sont référencés chez leurs éditeurs, pas recopiés.
